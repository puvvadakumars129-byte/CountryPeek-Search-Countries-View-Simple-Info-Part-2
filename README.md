# CountryPeek 🌍

A React application that lets users search for countries, browse basic information at a glance, and explore detailed data for any country they are curious about. Powered by the [RestCountries API](https://restcountries.com/).

## Tech Stack

- [React 18](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [React Router v6](https://reactrouter.com/)

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173`.

## Project Structure

```
src/
├── components/      # Reusable UI pieces
├── context/         # React Context providers
├── hooks/           # Custom React hooks
├── pages/           # One file per route
├── store/           # Redux store and slices (Part 5)
├── styles/          # Global CSS
├── App.jsx
└── main.jsx
```
